# Phase 3 Admin Dashboard — Design Notes

The admin dashboard uses the supplied AdminFlux and StrataFleet references as functional direction, not as a pixel copy. It keeps AutoLux's black/gold visual identity and introduces:

- persistent left navigation for Overview and Vehicles & Fleet;
- KPI cards for total vehicle records, published listings, rental listings and branches;
- fleet status counts and category mix;
- recent fleet status changes from the audit history;
- a dark, map-inspired branch footprint illustration.

The map is explicitly labelled illustrative. No GPS, telematics, live vehicle positions or geofencing is claimed in this phase. The supplied references show orders, payments, drivers, assets and live map tracking; those capabilities are planned for later phases and are not presented as implemented controls here.
